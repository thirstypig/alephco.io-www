What the rule asks

PFAS rules are set state by state

There is no single US PFAS rule for products. Which law applies depends on the product category and where it is sold.

State by state

Several states, including Maine and Minnesota, have their own PFAS rules for products, with different categories, triggers and dates. Check each state’s current law for your products.

A federal report too

EPA’s TSCA PFAS reporting rule (40 CFR part 705) reaches manufacturers and importers, including PFAS in imported articles.

PFAS you didn’t add

PFAS can come from treatments and manufacturing processes you don’t directly control, which is why supplier statements and test reports matter.

What Aleph does

One place for your PFAS evidence

Aleph does not tell you which state PFAS laws apply to a product. It keeps the evidence you gather on the product it belongs to.

Filed on the product

Upload a PFAS test report or supplier statement once and file it against every product it covers.

Read for you

Aleph reads each uploaded document and suggests its dates for you to confirm, rather than retype.

Expiry alerts

Give a test report or supplier statement an expiry date and Aleph alerts you before it lapses, so you can ask for a fresh one in time.

Materials checked against a PFAS list

Each confirmed material or ingredient is checked against Aleph’s PFAS list by exact CAS number or name. The list is a selection of PFAS, not every PFAS, and a match does not say whether a state rule applies.

In the Compliance Package

A product’s Compliance Package ZIP gathers the documents on file for it, so you can hand them over in one download.

Next to everything else

PFAS documents sit on the same product as its Prop 65, CPSIA, REACH or MoCRA records.

What you still do yourself

Which laws apply stays your call

  • Work out which state PFAS laws, and whether EPA’s report, apply to each product — with your advisor.
  • Ask suppliers for statements and order the tests; read the results against each rule.
  • Make any state notification or EPA report yourself. Aleph does not file anything.
